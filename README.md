## ✨ Features

- 🎯 **Pixel-accurate UI** — navbar, search bar, and category menu modeled after Amazon's real layout
- 🛍️ **Product grid** with cards, pricing, and ratings
- 📱 **Fully responsive** — looks great on desktop, tablet, and mobile
- 🎨 **Clean, semantic HTML5 & modern CSS3** (Flexbox / Grid)
- ⚡ **Zero dependencies** — no frameworks, no build tools, just clean code

## ⚙️ Getting Started

Want to run it locally? It's as simple as it gets:

```bash
# Clone the repository
git clone https://github.com/your-username/amazon-clone.git

# Move into the project folder
cd amazon-clone

# Open index.html in your browser — that's it!
```

No `npm install`, no build step. Just open and go.
